# SafeRoute AI

## Problem
During emergencies such as floods, fires, heavy rainfall and accidents,
the shortest route may not always be the safest route.

## Solution
SafeRoute AI analyzes route conditions and helps users identify safer
routes during emergency situations.

## Features
- Emergency-aware route planning
- Hazard detection
- Safe route recommendation
- Interactive map
- Emergency alerts

## Technologies Used
- Android
- Java/Kotlin
- Google Maps API
- AI
